# SamayShift

Website for **SamayShift**, a mobile-first shift-scheduling app for small businesses. Static HTML, CSS, and vanilla JS — no build step.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Files

| File | Purpose |
|------|---------|
| `index.html` | The site (single page) |
| `styles.css` | Styles and design tokens |
| `assets/` | Vector image assets (SVG) |
